## 4. 命名规范

| 对象 | 规则 | 例 |
|------|------|-----|
| 文件夹 | PascalCase，不用空格 | `LevelRuntime`、`SharedModels` |
| 脚本 | PascalCase，**文件名必须等于类名** | `GameFlowController.cs` |
| 场景 | `Level_NN`，衔接场景 `SharedArt_Lxx_Lyy` | `Level_04B.unity` |
| 预制体 | PascalCase；关卡专属加 `Lnn_` 前缀 | `L01_Content.prefab` |
| UI 资源目录 | `NN_英文名`，编号对应游戏流程 | `03_Pause` |
| 编辑器菜单 | 一律挂在 `Tools/DoNotLeaveMe/` 下 | |
| 组件菜单 | 一律 `DoNotLeaveMe/xxx` | |

**禁止在文件名里出现**：U+2011 非断连字符、双空格、撇号、全角括号。这些字符在脚本里做字符串匹配会莫名失败，2026-08-30 已清理 59 处。

## 5. 改名时必须同步的四个地方

Unity 的资产引用走 GUID，改名不会断引用 —— **但下面四类是按名字/路径工作的，改名必须手动同步**：

1. **`ProjectSettings/EditorBuildSettings.asset`** —— 场景路径写死在这
2. **场景里序列化的场景名字符串** —— `Persistent.unity` 的 `routeCatalog`、各关的 `successorScene`、`levelIntroScene` 等
3. **代码里的字符串常量** —— `SceneManager.LoadScene("…")`、`Resources.Load("…")`、`scene.name.StartsWith("…")`、按名字找预制体的 `"HumanVisual"` / `"PivotDoor_Door3"`
4. **`Resources/` 下的路径** —— `Resources.Load` 的参数是相对 `Resources/` 的路径，改文件夹名等于改加载路径

改完用这条命令自查有没有漏网：

```bash
grep -rn "旧名字" --include=*.cs --include=*.unity --include=*.prefab --include=*.asset Assets/
```

## 6. 归档规则

不再使用的东西**移进工程根目录的 `_ArchivedAssets/`，不要直接删**。放在 `Assets/` 外面 Unity 就不会导入它 —— 不占 Library、不拖慢导入，文件却还在硬盘上。判断「是否还在用」的方法不是看修改时间（整个工程可能是同一次拷贝，时间全一样），而是**从 Build Settings 里的场景做 GUID 传递闭包**，看资产是否可达。

`_ArchivedAssets/` 现有内容（详见该目录下的 README.md）：

| 目录 | 是什么 |
|------|--------|
| `Scenes_SuperBreadManEra/` | superbreadman 一代场景。**别删** —— `Docs/Reports/LevelXXSourceManifest.md` 记录的美术来源就是这批场景 |
| `Scenes_PrototypeEra/` | Primitive 原型期的 10 个关卡场景 |
| `PrefabsPrototype/` | 原型期 Primitive 预制体（Human / Dog / Monster / 各类机关） |
| `CharactersOldVersion/` | 被 `Art/Characters/` 取代的 6 套旧角色 |
| `UnusedModels/` | 早期试的模型，从没进过场景（111 MB） |
| `TJGenerators/` | Tripo 生成器的 History 缓存 |
| `SharedModels_OldCharacters/` | 5 个指向旧角色模型的无引用预制体 |

> **注意**：归档前务必确认没有正式关卡引用它。2026-08-30 就踩过一次 —— `Persistent.unity` 引用的 `Global Volume Profile.asset` 躺在 superbreadman 旧场景文件夹里，差点被一起归档。现已移到 `DoNotLeaveMe/Rendering/GlobalVolumeProfile.asset`。

> **查引用要查两个方向**：既要查「归档的东西还被谁用」，也要查「活着的文件里有没有还指向归档目录的」。后者查出过 5 个漏网的 SharedModels 预制体。
